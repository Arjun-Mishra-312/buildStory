# Model and provider marks

These SVG marks identify LLM providers next to model names across Buildstory
(receipts, recap ranked lists, model mix, explore, feed). They are used as
nominative identifiers, not as endorsement.

Sources:

- Simple Icons v16 (brand SVG pack): Anthropic, Claude, Cursor, Qwen, DeepSeek,
  Mistral, Ollama, Gemini, Perplexity, Hugging Face, Meta, Git, GitHub Copilot,
  Kimi, MiniMax
- Wikimedia Commons (PD-textlogo / trademarked): OpenAI blossom (2025), xAI
- Geometric letter mark for Z.ai (no public SVG was available)

Do not recolor a mark into a different brand. CSS `mask-image` tints marks with
`currentColor` so they stay legible on cream, cobalt, coral, amber, and green.
