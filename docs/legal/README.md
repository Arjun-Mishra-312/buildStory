# Legal drafts

`terms-of-service-draft.md` and `privacy-policy-draft.md` are working
drafts written from the product's actual implemented behavior, meant to
save a lawyer time — not published, reviewed, or binding. Every
`[BRACKETED]` field needs a real decision before either becomes real.
Neither is wired into a live site route (no `/terms` or `/privacy` page
exists yet) — that should happen only after review, at which point the
reviewed text should replace these drafts and get linked from
`components/site-footer.tsx`.
